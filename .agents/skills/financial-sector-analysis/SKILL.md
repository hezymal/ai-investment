# Финансовый сектор

Проверьте тип организации, лицензию, группу/юрлицо, стандарт и период. Подготовьте
данные по общему контракту с правильным `entity.sector`. Базовый калькулятор не
рассчитывает для финансовых компаний Net debt / EBITDA или промышленный денежный поток.

- **Банк:** качество кредитного портфеля, просрочка/стадии обесценения, резервы,
  стоимость риска, чистая процентная маржа, доходность капитала, структура фондирования,
  ликвидность и регуляторный капитал. Регуляторные нормативы берите из текущего
  официального раскрытия и правил ЦБ, не из запомненных универсальных порогов.
  ROE требует среднего сопоставимого капитала, а не только остатка на конец года.
- **Страховщик:** качество страхового результата, убыточность и расходы,
  достаточность резервов, перестрахование, инвестиционные активы, капитал и ликвидность.
  Смена стандартов/методики может разрывать сопоставимость рядов.
- **Другая финансовая компания:** определите бизнес-модель (лизинг, брокер, биржа,
  холдинг). Для лизинга исследуйте портфель, просрочку, стоимость фондирования и
  ликвидность; для брокера — клиентские/собственные активы, концентрацию и капитал.
  Не переносите банковские нормативы на все финансовые компании.

Для субординированных облигаций изучите триггеры списания/конвертации, очередь
требований и дискреционность купона; рейтинг старшего долга не заменяет оценку выпуска.
Если специализированные сведения недоступны, выдайте частичный анализ.
