# Наблюдение

`watch_add` добавляет эмитента из реестра, `watch_list` показывает список и ожидающие
события, `watch_check` проверяет страницы. Первая успешная проверка задаёт исходный
список; следующие сохраняют новые ссылки. Ошибка источника не очищает список.

Фоновый запуск не установлен. Для разовой просьбы выполните одну проверку; для
регулярной просьбы настройте явно согласованный пользователем планировщик на
`python -m moex_analyst watch-check` в окружении и корне проекта. Для Codex automation
используйте доступный инструмент автоматизаций, не изменяя расписание без такого запроса.

Если есть pending event, проверьте тип, период и содержание нового документа.
Выполните `investment-research`, сохраните новый Analysis с `entity.id`, равным
идентификатору реестра, и точным URL документа в sources. Затем вызовите
`watch_acknowledge(event_id, analysis_id)` и сравните с прошлой версией.

Не подтверждайте событие до сохранения анализа. Изменение содержимого PDF по старому
URL текущая проверка не обнаруживает; не обещайте полное отслеживание всех публикаций.
При неизменном состоянии регулярная проверка не должна создавать новый одинаковый отчёт.
