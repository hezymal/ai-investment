# История

Используйте `list_analyses(query)` для поиска по компании, ИНН или выпуску, затем
`read_analysis(id)`. История находится в `.local/history/` текущей копии проекта.
Не ищите историю другого пользователя и не включайте `.local/` в коммит.

`save_analysis` всегда создаёт новую версию. Перед сохранением проверяйте контракт
в `docs/analysis-contract.md`; `complete` допустим только без известных пробелов.

Для «что изменилось» выберите две записи одного эмитента и инструмента, вызовите
`compare_analyses`. Инструмент сравнивает совпадающие периоды отдельно от добавленных:
пересмотр числа за прошлый год не равен росту год к году. Динамику разных лет рассчитывайте
из сопоставимых метрик кодом, после проверки периметра и масштаба.

Покажите дату каждого анализа, новые документы, изменившиеся риски, закрытые пробелы
и изменение вывода. Если найдено несколько выпусков, уточните нужный.
Если история содержит повреждённую запись, сообщите об ошибке из `errors`, не удаляя её.
