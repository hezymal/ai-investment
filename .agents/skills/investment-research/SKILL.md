# Полный анализ

Работайте из корня проекта. Прочитайте `docs/analysis-contract.md` до подготовки данных.

1. Определите намерение: облигация, акция, анализ эмитента или обновление. Если компания
   не названа, уточните её. `search_securities` возвращает кандидатов, а не автоматически
   выбранный выпуск. При неоднозначности покажите короткий список; уточните ISIN/SECID.
   Получите `get_security`, выберите соответствующий рынок и режим торгов из `boards`.
2. Определите юридического заёмщика, группу и поручителя; проверьте сектор. Для банков,
   страховщиков и прочих финансовых компаний откройте `financial-sector-analysis`.
   Для инвестиционного вывода уточните горизонт и отношение к риску, если это меняет оценку.
3. Посмотрите `list_analyses` и прошлые пробелы. Для получения и анализа МСФО
   откройте `.agents/skills/ifrs-analysis/SKILL.md`.
4. Для РСБУ используйте `ras-analysis`, для понимания бизнеса — `annual-report-analysis`.
   Для остальных документов используйте `list_issuers`/`find_reports`, `list_report_links`
   (не более трёх вложенных страниц за один поиск), официальный сайт через доступный
   веб-поиск или документ пользователя. Для анализа облигации также получите условия выпуска.
5. Для облигации используйте `issuer-credit-analysis` и `bond-analysis`;
   для акции — `equity-analysis`; для альтернатив — `bond-comparison`.
6. Сформируйте Analysis по схеме `get_analysis_schema`. У каждой цифры должны быть
   источник, период, единицы, масштаб, периметр и страница/API-поле. Финансовые инструменты
   сохраняйте вместе с `bond` или `equity` inputs, чтобы расчёты можно было повторить.
7. Выполните `validate_analysis`, затем `save_analysis` с графиками. Скилл `analysis-history`
   объясняет сравнение с прошлой версией. Завершите кратким выводом, ключевыми рисками,
   условиями пересмотра и ссылкой на сохранённый отчёт.

В случае отказа источника продолжайте доступную часть и ставьте `status: partial`.
Не превращайте отсутствие новостей в доказательство отсутствия рисков. Не выдавайте
автоматическую метку «покупать» только на основании одного коэффициента или высокой доходности.
Команды CLI при недоступности MCP перечислены в README.
