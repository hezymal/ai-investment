# Анализ выпуска

Уточните SECID/ISIN и дату расчётов. Получите `get_security`, затем `get_quote` с
правильным режимом торгов. Время последней сделки и дата расчётов — разные даты.

1. Проверьте валюту, номинал на дату расчётов, погашение, купон, амортизацию,
   оферты/call, субординацию, обеспечение и ограничения. Используйте решение о выпуске.
2. Получите все страницы `get_bond_schedule` для coupons, amortizations, offers.
   Будущий неизвестный купон не равен нулю. Пустой блок не доказывает отсутствия особых условий.
3. Выполните `issuer-credit-analysis`. Ликвидность оцените по доступным оборотам,
   частоте сделок и спреду; не делайте её высокой только из факта листинга.
4. Соберите BondInput по примеру `examples/demo-bond.json`. `nominal` — оставшийся
   номинал; `accrued_interest` — рубли на одну бумагу, согласованные с датой расчётов;
   `clean_price_percent` — проценты номинала. Выплаты агрегируйте по датам.
5. Вызовите `calculate_bond`. Для договорного расчёта нужны фиксированные/нулевые купоны,
   подтверждённый график, полное погашение номинала, отсутствие сложных условий.
   Амортизация поддерживается явными выплатами principal, без повторного полного номинала в конце.
6. Флоатер/переменный купон, оферта/call, субординированная или бессрочная бумага:
   укажите `mode: scenario`, `scenario_name`, допущения и явные будущие выплаты.
   Для бессрочной бумаги задайте горизонт и предполагаемую цену выхода как финальный поток;
   это не обещанное погашение. При отсутствии сценария оставьте доходность неопределённой.

Результат расчёта — эффективная годовая ACT/365F до налогов и комиссий. Он может
отличаться от биржевой конвенции. IRR предполагает исполнение заданных выплат и не
является гарантированной доходностью. Сохраните input в `Analysis.bond`, чтобы
результат пересчитывался в истории. Отдельно объясните кредитный и процентный риски.
