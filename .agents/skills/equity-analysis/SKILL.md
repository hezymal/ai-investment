# Анализ акций

Уточните класс акции, SECID и горизонт. Используйте `annual-report-analysis`,
`ifrs-analysis`, при необходимости `ras-analysis` и `financial-sector-analysis`.

1. Получите котировку с временной меткой. Проверьте число акций, казначейские акции,
   привилегированные классы и возможное размытие. Для капитализации всей компании
   с несколькими классами требуются их отдельные рыночные стоимости; простой калькулятор
   предполагает одну однородную базу обыкновенных акций.
2. В `calculate_equity` передавайте деньги в единицах одной валюты, прибыль и капитал,
   относимые к обыкновенным акционерам. Укажите FY/TTM и дату. EV учитывает net debt,
   minority interest и preferred equity; не подставляйте нули вместо неизвестных существенных корректировок.
3. Отрицательная прибыль делает P/E неприменимым. Для банков/страховщиков не применяйте
   EV/EBITDA. Подбирайте аналоги по бизнесу, периметру и периоду; разница мультипликаторов
   без объяснения различий не доказывает недооценённость.
4. Изучите дивидендную политику, решения органов управления, денежное покрытие выплат
   и ограничения. Исторические дивиденды не равны будущим.
5. Создайте несколько сценариев через `calculate_equity_scenarios`: EPS, P/E,
   суммарный дивиденд за горизонт, срок и обоснованные допущения. Укажите чувствительность,
   не выдавайте единственную точную справедливую цену.

Сохраните input в `Analysis.equity`, итоговые допущения и сценарии в findings/assumptions.
Вывод должен объяснять связь цены, ожиданий и рисков, а не только качество бизнеса.
