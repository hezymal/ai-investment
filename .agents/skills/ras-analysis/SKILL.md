# Анализ РСБУ

Прочитайте `docs/analysis-contract.md`. Проверьте ИНН, наименование и отчётный период
на титульной странице. Бухгалтерская отчётность материнской компании не равна отчётности группы.

1. Используйте документ эмитента, доступную выгрузку ГИР БО ФНС или файл пользователя.
   Для ФНС автоматический массовый API не подключён: при ограничении доступа нужна выгрузка.
2. Изучите баланс, финансовые результаты, движение денежных средств при наличии,
   пояснения и аудиторское заключение. Укажите отсутствующие формы.
3. Отразите собственный капитал, кратко- и долгосрочный долг, денежные средства,
   дебиторскую и кредиторскую задолженность, выручку, прибыль и процентные расходы.
   Перечень строк проверяйте по форме конкретного года; номера строк не заменяют проверку содержания.
4. Проверьте крупные займы связанным сторонам, качество дебиторской задолженности,
   сроки обязательств, залоги и поручительства. Для холдинга оцените источник денег
   на обслуживание долга, не приписывая ему денежные средства дочерних компаний.
5. Сопоставляйте с МСФО отдельной таблицей по периметрам. Разницу показателей объясняйте,
   а не складывайте. При отсутствии МСФО обозначьте ограниченный охват группы.

Сохраняйте `standard: RAS`, `scope: standalone`, точный `entity_id`, страницы и единицы.
В выводе отдельно ответьте, что известно о юридическом заёмщике и что — только о группе.
