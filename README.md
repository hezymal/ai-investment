# MOEX Analyst

Локальный проект для анализа компаний МосБиржи в Codex: напишите «Хочу купить
облигации компании X», чтобы уточнить выпуск, разобрать отчётность, проверить
расчёты и сохранить результат с графиками. Акции, сравнение выпусков и повторный
анализ используют ту же историю и источники.

**Версия 0.1.0:** 12 проектных скиллов, три STDIO MCP-сервера, CLI, локальные
отчёты и список наблюдения. Интерпретацию выполняет Codex; отдельный OpenAI API
ключ и сервер приложения не нужны. Это первая реализация с ограниченным
покрытием источников, а не база готовых анализов всего рынка.

## Быстрый запуск

Нужны Python 3.11+ с pip, Git и Codex. Windows, Linux и macOS поддерживаются.

```powershell
git clone https://github.com/hezymal/ai-investment.git
cd ai-investment
python scripts/bootstrap.py
```

В Windows при необходимости используйте `py -3` вместо `python`. Скрипт создаёт
`.venv`, устанавливает проект и генерирует **локальную** `.codex/config.toml`
с абсолютными путями. Существующая пользовательская конфигурация не перезаписывается.
Установка зависимостей требует доступа к PyPI.

Откройте папку в Codex, подтвердите доверие проекту и начните новую задачу.
Проектные скиллы лежат в `.agents/skills`; MCP: `moex_market`, `moex_documents`,
`moex_research`. Если MCP ещё не появился, перезапустите клиент/задачу.
Проектные конфигурации MCP загружаются для доверенных проектов; механизм описан в
[документации Codex](https://learn.chatgpt.com/docs/extend/mcp).

Запросы для начала:

- «Разбери этот PDF по МСФО, покажи денежные потоки и риски». Файл поместите в `.local/inbox/`.
- «Хочу купить облигацию [ISIN]. Оцени эмитента и условия выпуска».
- «Сравни эти два выпуска на одну дату расчётов».
- «Покажи мои прошлые анализы компании и объясни, что изменилось».
- «Проанализируй акции [тикер]: бизнес, дивиденды и сценарии оценки».

## Проверка без реальных данных

После установки в Windows:

```powershell
.\.venv\Scripts\python.exe -m moex_analyst validate examples/demo-analysis.json
.\.venv\Scripts\python.exe -m moex_analyst save examples/demo-analysis.json
.\.venv\Scripts\python.exe -m moex_analyst bond examples/demo-bond.json
.\.venv\Scripts\python.exe -m moex_analyst history
```

В Linux/macOS используйте `.venv/bin/python`. Все данные в `examples/` вымышленные.
Команда `save` выводит абсолютный путь к Markdown-отчёту с PNG-графиками.
Сохраняются исходные метрики, источники и воспроизводимые расчёты; новый запуск
не перезаписывает предыдущий. История читается из любой новой задачи в этой папке.

Другие команды: `schema`, `show ID`, `compare OLD NEW`, `search QUERY`, `security SECID`,
`reports rosneft`, `extract PATH --page 1 --count 30`, `equity FILE`, `compare-bonds FILE`,
`watch-add rosneft`, `watch-list`, `watch-check`, `watch-ack EVENT ANALYSIS`.
Для другой рабочей папки укажите `--workspace PATH` перед подкомандой.

## Что реализовано

| Область | Возможности |
|---|---|
| Отчётность | Скиллы МСФО, РСБУ, годового отчёта; извлечение текста PDF с номерами страниц |
| Компания | Методика кредитного анализа; отдельные маршруты для банков, страховщиков, лизинга и других финансовых компаний |
| Облигации | Цена с НКД, эффективная доходность ACT/365F, дюрация, выпуклость; амортизация через явные выплаты |
| Сложные выпуски | Флоатеры, call/оферты, субординация и бессрочные бумаги — только явно заданные сценарии, без выдачи сценария за гарантированный график |
| Акции | P/E, P/B, EV/EBITDA для подходящего бизнеса, дивидендная доходность и сценарии EPS × P/E |
| Данные | ISS: поиск, описание, котировки, свечи, история, выплаты; ЦБ: ключевая ставка |
| История | Неизменяемые снимки анализа, сравнение периодов и рисков, локальные графики |
| Наблюдение | Новые ссылки в настроенных источниках, очередь событий до сохранения повторного анализа |

Автоматический поиск документов пока настроен для страниц Роснефти и Ростелекома в
`config/issuers.json`. Для других эмитентов добавьте проверенные страницы в
`.local/issuers.json` в том же формате либо используйте официальный URL/файл.
MCP `list_report_links` открывает вложенную страницу со списком документов.
Проверяется HTML со ссылками; динамические страницы, CAPTCHA и ZIP не разбираются.
ГИР БО ФНС используется через документ пользователя; массового API ФНС нет.
Кредитные рейтинги и существенные события проверяются скиллом по первичным
публикациям через доступный поиск, отдельной рейтинговой подписки нет.

PDF-экстрактор не распознаёт сканы и не подтверждает правильность таблиц.
Требуются визуальная сверка/OCR доступными средствами. Полнота анализа зависит
от документов; при пробелах отчёт имеет статус `partial`. Системного планировщика
и фонового LLM-анализа нет: `watch-check` запускается вручную или выбранным пользователем
планировщиком, а скилл ведёт повторный анализ по событиям.

## Разработка и публикация

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe scripts/check_skills.py
.\.venv\Scripts\python.exe scripts/check_public_files.py
git diff --check
```

`scripts/smoke_live.py` отдельно проверяет доступ к живым источникам. Сетевые ошибки
не заменяются фиктивными или устаревшими значениями. Обычные тесты работают без сети.
GitHub Actions запускает проверки на Windows и Ubuntu. Совместимые диапазоны зависимостей
заданы в `pyproject.toml`; для воспроизведения проверенного окружения — `requirements.lock.txt`.

В GitHub входят код, скиллы, документация и синтетические примеры. `.local/`,
скачанные отчёты, локальная конфигурация и секреты исключены из Git. История
принадлежит владельцу локальной копии; резервную копию `.local/` он хранит отдельно.

Данные ISS могут предоставляться с задержкой, а их использование и распространение
имеют отдельные условия: [МосБиржа, ISS](https://www.moex.com/a2193).
Лицензия проекта не распространяется на биржевые данные и документы эмитентов.
