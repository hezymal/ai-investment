# Контракт анализа v1

Схема доступна через MCP `get_analysis_schema` или `python -m moex_analyst schema`.
Заполняемый пример — `examples/demo-analysis.json`; все его значения синтетические.

## Общая запись

`query`, `entity`, `asset_type` (issuer/bond/equity), `instrument` (SECID/ISIN),
`as_of`, `status` (partial/complete), `sources`, `metrics`, `summary`, `findings`,
`strengths`, `risks`, `gaps`, `assumptions`, `conclusion`.
`related_entities` хранит другие юридические лица/группу/поручителей отдельно.
`entity.id` — стабильный идентификатор (для реестрового эмитента используйте id реестра);
ИНН — отдельное поле. Не меняйте id между анализами одной компании.

`bond` и `equity` — необязательные исходные данные для калькуляторов, в формате
соответствующих примеров. Для анализа конкретной бумаги сохраняйте их, если данных
достаточно. Расчёты автоматически повторяются при сохранении. Сценарии стоимости
акций фиксируйте в findings как assumptions вместе с входами, результатами и горизонтом.

## Источники и факты

У источника есть `id`, `title`, `location` (URL/путь), `retrieved_at` в ISO 8601,
необязательные `published_on`, `period`, `sha256`. Время загрузки не равно публикации.
Для загруженного PDF используйте хеш из инструмента; первичный URL сохраняйте в location.
Facts в `findings` требуют `source_ids`; interpretation и assumption маркируются явно.

## Метрики

- `name`: идентификатор показателя, например `revenue`, `net_income`, `ebitda`,
  `ebit`, `operating_cash_flow`, `capex`, `total_debt`, `cash`, `interest_expense`.
  Другие названия разрешены для отраслевых показателей.
- `value`: число или null; `scale`: 1/1000/1000000; `unit`: currency/percent/ratio/shares/units.
  Денежные показатели содержат `currency`. CAPEX и процентный расход — положительные расходы.
- `period_start`, `period_end`: ISO-даты; `period_kind`: instant/FY/H1/Q1/9M/TTM.
  Остатки баланса — instant, start=end; потоки — точные даты периода.
- `standard`: IFRS/RAS/management/market/regulatory; `scope`: consolidated/standalone;
  `entity_id` указывает, кому принадлежит цифра.
- `source_ids`: существующие источники; `locator`: страница/таблица/строка либо API-поле;
  `note`: определение, корректировки и пересчёт сравнительных данных.

Запрещено складывать разные периметры, заменять пропуски нулями и смешивать валюты.
Калькулятор нормализует масштаб и группирует по стандарту, компании, валюте и периоду.
Net debt/EBITDA вычисляется только для FY/TTM и положительной EBITDA; отрицательные
значения EBITDA не означают нулевой долг. Для финансовых компаний промышленная методика отключена.

## Итог и история

`partial` обязателен при gaps или пропущенных числах. `complete` означает полноту
заданного объёма работы, не гарантирует качество инвестиции. Укажите ограничения
актуальности и конкретные условия пересмотра вывода.

Снимок в `.local/history/ID/` содержит `analysis.json`, `calculations.json`,
`report.md`, `metadata.json`, `charts/`. Незавершённые записи `.pending-*` не
отображаются в истории. Документы лежат отдельно по хешу в `.local/documents/`;
их удаление не удаляет отчёт, но может затруднить проверку источника.

Сравнение снимков сохраняет различия стандартов, компаний и периодов. Новый
год показывается как добавленный период, пересмотр старого — как revised.
Процент изменения не вычисляется от нулевой/отрицательной базы.
