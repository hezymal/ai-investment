# Этапы и состояние первой реализации

Каждый этап исходной дорожной карты получил рабочую основу. Версия 0.1.0 остаётся
начальным релизом: наличие метода не означает проверенное покрытие всех компаний.

| Этап | Реализовано | Следующее расширение |
|---|---|---|
| 1. Проект/GitHub | README, AGENTS, настройка, CI, разделение личных данных | Пакетные релизы после использования |
| 2. Контракт | Валидируемый Analysis v1 и Markdown-отчёт | Версионирование миграций при смене схемы |
| 3. МСФО | Скилл, PDF-текст, показатели, примечания | Проверенные отраслевые примеры и OCR |
| 4. История | Неизменяемые снимки и сравнение | Удобный экспорт личного архива |
| 5. Графики | Финансовые PNG, цена/объём | Настраиваемые панели и диапазоны |
| 6. РСБУ | Скилл с разделением юрлица/группы | Дополнительные проверенные формы |
| 7. ISS MCP | Поиск, описание, board-котировки, ряды, выплаты | Проверка большего числа режимов |
| 8. Документы MCP | Реестр страниц, ссылки, PDF, хеши | Дополнительные эмитенты, адаптеры динамических сайтов |
| 9. Надёжность | Скилл, долговые расчёты, методика событий/рейтингов | Специализированные источники рейтингов |
| 10. Облигации | YTM/IRR, НКД, дюрация, амортизация | Верификация биржевых конвенций и календарей |
| 11. Чат | Скилл маршрутизации и общий поток сохранения | Пользовательские оценки реальных разборов |
| 12. Сравнение | Общая дата, результаты по выпускам, ставка ЦБ | Кривая ОФЗ и устойчивые спреды |
| 13. Акции | Бизнес, мультипликаторы, EPS × P/E сценарии | DCF и автоматическая подборка аналогов |
| 14. Расширение | Отраслевые методики, сценарии сложных выпусков, watchlist | Автоматическое извлечение условий флоатеров, обнаружение замен PDF по старому URL |

## Последующие контрольные версии

- 0.2: сверка нескольких реальных МСФО/РСБУ с ручным эталоном, расширение реестра;
  устойчивый сценарий обычной облигации от поиска до отчёта.
- 0.3: дополнительные сравнения выпусков и эталонные разборы акций.
- 0.4: специализированные отраслевые эталоны и более полное наблюдение.

Уже реализованные компоненты можно применять сейчас в пределах описанных ограничений.
Не считать непроверенные источники, OCR или биржевые правила доходности завершёнными.
